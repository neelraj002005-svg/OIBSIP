
# FocusFlow - Productivity Landing Page

## About the Project
FocusFlow is a responsive landing page designed to encourage better productivity, time management, and daily planning.

## Features
- Navigation bar with Home, Features, and Contact links
- Hero section with a call-to-action button
- Three feature cards:
  - Smart Planning
  - Stay Focused
  - Track Progress
- Contact section with a Contact Us button
- Responsive layout for desktop and mobile screens
- Hover effects and smooth scrolling

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## How to Run
1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in a web browser.
